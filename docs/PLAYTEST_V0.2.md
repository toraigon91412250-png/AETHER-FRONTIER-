## 修正内容
1. 剣操作で発射されていた60m級の自動追尾弾を廃止。近接判定はモーション開始から0.18秒後に一度だけ行う。
2. ボスは平面距離12.5m以内、ドローンは5.2m以内で攻撃可能。向きの判定も入れる。近接武器としての当たり判定はプロトタイプであり、厳密な刃先とモデルとの交差判定ではない。
3. 横→返し→強攻撃の3連撃。右左に振り分けるアニメーションと簡易的な斬撃軌跡を追加。
4. 画面中央付近に HIT / MISS / 射程外 / 被弾 / ブレス予兆を表示。ボスが攻撃準備中の命中は弱点ボーナス。
5. city/district/islands の描画ON/OFFを絶対X/Zの境界から、半径と100mのヒステリシスへ変更。飛行中に街が突然消える問題の緩和を狙う。元のcity等のアセットは改変なし。
6. HP、ボス戦の進行と既存セーブキーは変更しない。

## 静的検証
- GitHubにHTML 1件追加済み。commitに含まれ、復元できることを確認。
- HTMLの開始・終了タグ、近接処理、HUD、更新処理、視界切替処理が存在することを確認。
- 旧自動追尾攻撃が新しい`attack`関数に残っていないことを確認。
- **JavaScript構文をNodeで実行する検査、PC/iPhone SafariでのWebGL描画・fps・操作検査は未実施。** 結果を保証しない。

## 実機で重点確認
1. FPS/TPSの両方で剣が自然に振れるか（攻撃直後、2〜3連撃、移動中）
2. 離れたドラゴンに剣でダメージが入らないか。近距離で命中するか
3. ブレス予告→横移動回避→攻撃チャンスが分かるか
4. 飛行艇で都市周辺を旋回しても建物の突然の出現・消失が緩和されたか
5. 描画範囲が広くなった結果、iPhone 16でfpsや一瞬の引っかかりが悪化していないか
