# AETHER FRONTIER / 20チーム統合試作

## 起動

ブランチのルートから `python3 -m http.server 8871` を実行し、`http://127.0.0.1:8871/playtest/work20/` を開く。配布の単体HTMLはThree.js r160を同梱する。配布ZIPはルートに統合試作の `index.html` があり、Cloudflare Pagesへの直接アップロードに使える。どちらもビルドは不要。

開始地点から少し北東の青い端末で E／調べるを押すと探索ゲートが開く。神殿・地下研究施設・工業プラント・荒野・空中戦艦を選択できる。各到着地点の端末で都市へ戻れる。飛行艇ではHUDの「航路」で飛行先を切り替えられる。艦は飛行艇で甲板へ降りることもできる。

- 神殿では東西の星印と中央の星核を操作し、奥の記録へ進む。
- 研究施設では西の冷却、東の同調器、記憶アーカイブを順に調べ、隔壁を開いて中枢へ進む。
- 工業プラントでは補助設備3系統と主制御盤を操作する。
- 荒野では記憶の収集、RIFT HOUNDの運転、VESTIGE-ΩとAEGIS-IXとの戦闘ができる。車は前後で加減速、左右で旋回、Shiftでブースト、Qでドリフト。減速してEで降りる。
- 空中戦艦は後部甲板右側のスロープから格納庫へ。シャッター端末とARCHAION XをEで操作できる。
- 剣はR／攻撃。連続で振ると横斬り、返し、縦斬り。剣の有効時間に敵が掃引範囲に入ると命中する。VHALKORはブレスを横に避け、硬直中に接近するとダメージが増える。

## 検証

- Node 24のSTEP03インポートと互換テストで20ファクトリーの読込と共通契約を確認。新規の実Three.jsテストでは座標・床・隔壁、甲板、車両、変形、天候API、剣の命中と空振りを検証。
- Chromium Headless 142 / SwiftShaderの実WebGLで段階1〜4の各コミットと単体HTMLを起動し、描画とキーボード移動を確認。
- 最終版のChromium操作テストは、4地区と都市の往復、神殿の星印、甲板からスロープへの歩行、格納庫の変形、地上車両の乗車・走行・降車、ゴーレム戦の空振りと勝利、AEGIS-IXのHP表示、飛行艇の甲板着陸、研究施設の中枢起動、既存保存キーの保持を確認。Chromiumのモバイルエミュレーションでタップによる視点切替と横はみ出しがないことも確認。
- 再現コマンド `node --test integration/tests/compat.test.mjs tests/step03-import.test.mjs tests/work20.test.mjs`。
- ブラウザ操作テスト `node tests/work20-browser.cjs /path/to/chrome-headless-shell`。ポート8871で配信する。操作テストの一部は装置や敵の近くへ座標移動し、入力と判定を検証する。配布版にはこの座標移動用のテストフックを含めない。

## 残課題

- iPhone 16のSafari実機での描画、タッチ、発熱・メモリ、50〜60fps目標の検証。
- 全ルートの連続プレイ、飛行艇での長距離移動、TPS/FPSの剣の見た目と当たりの最終調整。
- 神殿・研究施設・工業プラントの途中状態は同一プレイ中に保持。再読込後の途中状態復元は未実装。
- 艦の物理は固定位置の歩行床・スロープが中心。艦内全構造の衝突、動く艦への追従、艦そのものの操縦は未実装。
- 都市の遠景はシルエットへの切替。LOD境界でのシルエット差と低速端末のフレーム時間は要調整。
- 変形ロボットは格納庫で変形を操作できる。ロボット搭乗や機械竜の騎乗は未実装。
