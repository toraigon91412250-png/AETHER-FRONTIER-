# Work20｜HUD・剣モーション調整（No.00 / 2026-11-18）

## ユーザーフィードバック
- 画面中央の操作案内・現在状態の表示が野暮ったい
- FPS/TPSの剣の動きが不自然

## HUD
- 画面中央の `#prompt` を常駐させず、近くに操作可能なものがある場合だけ左上へ小さく表示
- `#flight` の速度・高度は右上の小さなテレメトリへ移動
- `#notice` は視界を遮らない画面端へ移動
- 十字照準・HP・敵HP・操作ボタン・開始画面は維持
- 既存CSSを維持し、`ui-refinement.css` に追加レイアウトを分離

## 剣の修正
- 剣モデルの `playAction('slash')` を廃止。外部の攻撃コントローラーと武器モデル内部で発生する二重回転を防止
- TPSでは右手首のグループに剣の柄を固定。肩・肘・手首が同じ `sword.pose` を読む
- FPSでは右手側の固定グリップを軸に刃先のみを回転
- 3段斬りの風切り動作（横斬り・返し斬り・縦斬り）にwindup / strike / recoverを導入
- フレーム中の当たり判定のあとに可視モーションを更新し、1フレーム遅れを減らす
- 旧版の攻撃ダメージ28/30/42を維持。命中は攻撃時間窓と実際の軌道で判定

## テスト

- 本番ゲームのPC／Safariでの視覚確認・FPS測定は未実施。見た目はプレイ確認後に調整が可能
