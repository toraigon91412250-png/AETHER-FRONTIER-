# Work20 視認性・軽量LOD改善（2026-11-18）
対象: 第二次統合版 Work20。原版20チーム、ルートのindex.html、セーブスキーマを変更しない。

## 原因・対策
- 起動時の16:30、7分周期の昼夜、52秒周期の天候により短時間で薄暗くなっていた。初期時刻を12:20前後、昼夜周期を30分、天候切替を115秒へ。昼夜と悪天候自体は残す。
- ACESトーンマッピングの露出を1.1から1.43へ。昼夜・地下エリアに合わせた下限付きの半球光・太陽光を適用。
- 霧の濃さと色を天候ヒントから求め、地下では距離を見通しやすくする。霧は遷移を平滑化。
- 金属表面が環境マップなしでほぼ黒くなるのを避けるため、メッシュの既存Standardマテリアルを軽量版で金属度0.56以下・粗さ0.45以上に調整。高品質版は金属度0.67以下・粗さ0.36以上。ジオメトリ、原版、マテリアル総数は増やさない。
- 遠方の中央都市の詳細モデルを、距離と高さを含むカメラ距離に応じて早めにシルエットへ切り替える。No.01徒歩探索の床やコリジョンは変えず、表示だけ切り替える。
- 輪郭や描画負荷が見えにくくなる元だった霧と金属の暗さを優先修正。単純なポリゴン削減はランドマークを損なうため実施せず、既存LODを活用。
