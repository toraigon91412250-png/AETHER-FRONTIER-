# Work向け作業依頼｜魔導剣 VESPER PRISM の根本的なアニメーション改修

## 背景
AETHER FRONTIER v0.1.2では「剣で攻撃」を押すと約60mのエネルギー弾を射出していたため、距離感・手応えが分かりにくく、剣を振る動作も不自然だった。
通常No.00で`playtest/combat-v0.2.html`を別途作成し、近接距離・向き判定、攻撃タイミング、3打のモーション、命中メッセージを追加した（既存`index.html`は変更なし）。ただし腕/手首/剣のモーションは暫定的な回転・移動で、まだ自然な剣術になっていない。

## Workが担当する範囲（将来の大型改修）
- No.15モデルは原則活かす。新しい剣モデルの作り直しではなく**武器の握り位置・肩/肘/手首と剣の連動**を改善。
- FPSとTPSの見え方を個別に調整。TPSで剣が腕と一緒に動き、FPSで画面を不自然に横切ったり視界をふさがない。
- 予備動作→振り抜き→戻し、右→左／返し／縦斬り、連撃受付、移動中/視点切替中の連続性。
- 攻撃の発生時刻と命中判定を統一し、命中したかどうかは視覚と音の両面で理解できるようにする。
- モバイル操作、保存互換性、fps、ギミック・飛行艇を壊さない。
- 完成前に実ブラウザでFPS/TPS、移動中、連撃、空振り、ボス近接戦を試す。
- Work使用量を抑えるため、他モジュールの大規模統合と同時期にまとめて作業するのが望ましい。

## 出発点
- 最新の既存本編: `index.html` (v0.1.2)
- 暫定近接テスト: `playtest/combat-v0.2.html`
- モジュール原版: No.15 VESPER PRISM ソースZIP（No.00添付）
