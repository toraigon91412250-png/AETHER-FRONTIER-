# AETHER FRONTIER | Team No.01
## AETHER CROWN · 中央都市とエーテルタワー

**バージョン:** 1.0.0 / 2026-11-08  
**担当:** 巨大中央都市の中心部とランドマーク  
**制作:** Three.js 0.160.0 / JavaScript ES Modules / ビルド不要  
**座標:** Y軸上、プレイヤー前方 -Z、1 Three.js単位 ≒ 1m

中央の環状広場「エーテル・クラウン」と約270mの「エーテルタワー」を持つ、歩いて探索可能なSFファンタジー都市中心部。古代魔法の共鳴回路、複層の機械式塔冠、浮遊島、展望環、4方向の外部地区接続ゲートを、**外部画像・モデル・音声なし**でプロシージャルに造形。

### 納品物

- `index.html`：**単体デモ（すべてのゲーム・世界コードを内包）**。Cloudflare Pages Direct Uploadでビルドなし公開可。
- `src/aether-module.js`：ゲーム本体統合用。`export function createAetherModule(THREE,options)` を公開。
- `demo/demo-controller.js`：デモの移動・カメラ・タッチUI・描画処理。統合先では利用不要。
- `demo/style.css`：デモのHUDスタイル。統合先では利用不要。
- `docs/INTEGRATION.md`：API、座標、接続位置、探索イベント、パフォーマンス注意点。
- `tests/module-smoke.mjs`：Node.jsの構造・ロジックテスト。WebGL実機テストではない。

### 公開方法

1. `index.html` **だけ**をCloudflare Pagesの直接アップロード画面へアップロードする。単体HTMLをアップロードする場合、配布した `AETHER_01_demo.html` を `index.html` にリネームしても同じ内容。
2. 公開先URLをSafariまたはPCブラウザで開く。
3. Three.js **0.160.0** は、起動時にCDN（jsDelivr→unpkgの順）から読み込む。初回利用時にインターネット接続が必要。画像・モデルなど追加アセットは不要。

このZIPにはビルド設定、`wrangler.toml`、`package.json`、`node_modules` を含めていない。Cloudflare Pagesのビルドコマンドも不要。なお外部CDNが使えないネットワークでは三次元表示は起動できない。

### 探索内容

- **中央広場:** 直径約280mの都市基壇の内部を探索。
- **エーテルタワー:** 高さ約270m、3層の浮遊リングと多数の斜め支柱を備えるランドマーク。
- **展望環:** 地上約64m。塔東側の転移台から移動し、降りる際も転移台を使用。
- **3つの共鳴碑:** 南・西・東。3つとも起動すると塔冠が活性化。
- **碑文と観測記録:** 都市の古代魔法と科学融合を示す小さな探索イベント。
- **4つの地区接続口:** 東西南北。No.01はゲートのみ制作し、他チームの商業・居住地区は占有しない。

### 軽量版と高品質版

| | 軽量版 `lite` | 高品質版 `high` |
|---|---|---|
| 3D構造 | 中央広場・タワー・4ゲート・展望環・共鳴碑 | 軽量版の全要素 |
| 描画オブジェクト | 約124（モジュールのみ、テスト上の概算） | 約163（モジュールのみ、テスト上の概算） |
| 追加ディテール | 省略 | 金属装飾、舗装彫刻、空中粒子、植栽 |
| デモ描画倍率 | 1.0 | PC最大1.85 / タッチ端末最大1.4 |
| デモの局所光源 | 省略 | PCのみ追加、タッチ端末は無効 |
| デモの雲模様 | 単色 | アニメーションシェーダー |

**50fps / 60fpsについて:** iPhone 16 Safari実機での性能測定は今回未実施。デモ右上にFPSと描画回数を表示しているので、実機検証時に確認可能。軽量版は負荷削減を優先しているが、実機の最低fps保証は含まない。

### 単体デモと統合用の境界

`createAetherModule()` はThree.jsの`Group`とゲーム固有の更新・探索APIだけを作る。**Scene / WebGLRenderer / Camera / ライト / 入力 / プレイヤーは作らない。** これらはデモHTML専用のコントローラ側が管理する。

統合側では`src/aether-module.js`だけを取り込む。`createAetherModule(THREE,{quality:'lite'})`の返す`root`を既存シーンに追加し、毎フレーム `update(dt,{playerPosition})` を呼ぶ。詳細は`docs/INTEGRATION.md`。
