# AETHER FRONTIER — Team No.11
## SERAPH-11 / 星環の機竜

**Status:** v1.0.0 / Three.js **0.160.0** / build tool **不要**

古代のエーテル結晶に自律型機械骨格が共生した機械生命体。中央の多面体クリスタル、開閉式アイリス、独立変形する装甲翼4枚、3軸の古代魔法環、回転するルーン文字、魔力探査パルスを持つ。SFと古代魔法の混合した造形。敵味方どちらにも使える3モード構成。

## 再生方法

- **最も簡単:** `AF11_SERAPH_11_LITE.html` または `AF11_SERAPH_11_HIGH.html` をブラウザで開く。
- **Cloudflare Pages:** ZIPファイルを展開せずにダッシュボードの直接アップロードに使う。`index.html` がルートにある。Wrangler設定ファイルやビルド設定は入れていない。
- **ソース構造でローカル試験:** `index.html` はECMAScriptモジュールを相対importするため、`file://` ではブラウザのCORS制限を受ける場合がある。Cloudflare PagesなどのHTTPSサイトで使用する。
- **ネットワーク条件:** Three.jsの実装本体はバージョンを固定した **jsDelivr CDN** から読み込み、失敗すると **unpkg CDN** を試す。単一HTML版に自作コードとスタイルはすべて埋め込まれているが、**Three.jsライブラリ自体は同梱していないため初回起動にネット接続が必要**。

## 操作

| 操作 | 内容 |
|---|---|
| ドラッグ、タッチスワイプ | カメラ回転 |
| ホイール、2本指ピンチ | カメラズーム |
| 友好 / 中立 / 敵対 | 発光色と翼展開状態の切り替え |
| 軽量 / 高品質 | ドローン詳細描画、飾り、ピクセル比などを切り替え |
| 翼を展開 | 最大展開 → 収納 → モード連動の自動変形に循環 |
| 探査パルス | 古代魔法の探査環を放出 |
| 自律飛行 ON / 手動操縦 ON | 巡航パターンとプレイヤー操作の切り替え |
| W / A / S / D、矢印 | 手動飛行（移動キー入力で自律飛行から自動切替） |
| Q / E | 下降 / 上昇 |
| Shift | 手動飛行の加速 |
| Space | 探査パルス |
| R | 機体の位置リセット |
| スマホ画面右下の矢印 | タッチによる手動飛行・上昇下降 |
| 停止 / 再生 | モデルアニメーション・操縦の停止・再開 |

## 設計・パフォーマンス

- 方向: **Y上、ローカル前方-Z、1単位 ≒ 1m**。
- 最大展開時の幅は**約4.4m**（概算、初期向きや揺れにより変わる）。
- ゲーム本編では `createAetherModule(THREE, options)` を使い、`root`を外部シーンに追加する。レンダラー、カメラ、入力、飛行経路はモジュール本体に含めない。
- 軽量版は高品質向け追加描画を無効にして、デモでは内部解像度を低くする。双方ともBloomなどの高負荷ポストプロセスなし。
- インスタンシングによる校正目盛り、材質とジオメトリの共有、影マップの不使用、`dispose()` によるリソース解放に配慮。
- FPS表示は**デモ稼働中の当該ブラウザでの簡易実測値**。50/60fpsは目標であり保証ではない。iPhone 16 Safari実機試験は未実施。

詳細は `docs/integration.md` と `docs/TEST_REPORT.md` を参照。
