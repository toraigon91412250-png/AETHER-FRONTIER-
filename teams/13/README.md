# AETHER FRONTIER｜開発チーム No.13
## VHALKOR（ヴァルコール）｜六重炉心の機械竜 v1.0.0

Three.js 0.160.0 を使用したオリジナルのゲーム用巨大機械竜。

### 内容

- `index.html`：単体で開ける展示デモ（描画にはインターネット接続が必要）
- `src/aether-dragon.js`：統合用の3Dモジュール。Three.js の名前空間を受け取ってインスタンスを作成
- `src/demo.js`：展示ステージ専用ロジック（本編へ組み込む必要なし）
- `INTEGRATION.md`：統合インターフェースと使用例
- `tests/test-module.mjs`：Three.jsを模したスタブによる構造テスト

> `index.html` はソースがインライン化された単体HTMLです。表示時のみ CDN の Three.js r160 を読み込みます。ビルド、npm、パッケージインストールは不要。Cloudflare Pages の直接アップロードに対応する構成です。

### モデル

- 胴体：多段ロフト装甲、背骨フィン、装甲継手、内骨格
- 頭部：別可動の顎、角、眼、牙、頸椎サーボ
- 翼：左右独立可動、翼骨、分割エーテル翼膜、発光パターン、外周スパー
- 尾：9節の階層型関節と先端エネルギー結晶
- 四肢：4脚、膝駆動、爪、レイヤー装甲
- 炉心：中心結晶、6つの封印、環状スタビライザー
- 追加演出：咆哮、炉心充填、エーテルブレス（見た目だけ）、飛行姿勢

寸法：翼幅約44m、全長約36m（尾を含む）。座標は Y上、前方 -Z、1単位約1m。

### 品質設定

- `high`：上位ディテール、翼膜の透過、儀式リングを有効化
- `low`：装飾158点と儀式リングを非表示、翼膜を不透明化。デモの遠景、粒子、描画解像度も軽量化

構造テストによる部品数は415メッシュ、低品質時は精密ディテール158メッシュが非表示となります。これは実機FPSの測定値ではありません。

### 操作（デモ）

- ドラッグ：カメラ回転
- ホイール／ピンチ：ズーム
- 画面下のボタン：待機、咆哮、充填、放射、飛行
- 自動展示ボタン：順次アニメーション
- HIGH / LITE：品質切替
- キーボード 1〜5：各演出、Space：自動カメラ旋回ON/OFF

### 対応と制限

PCブラウザと iPhone 16 Safari 向けに負荷を制御できる構造。ソース構造テストとJavaScript構文チェックは通過。今回の実行環境ではWebGL画面の表示、GPU負荷と実機FPSの計測はできていないため、iPhone 16での50fps維持は未検証。デモ右下には実測FPS／DRAW／TRIの表示を搭載。

Three.js 本体は同梱していません。CDN参照先：`https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js`。オフライン実行が必要な場合は公式 Three.js r160 のESモジュールをローカルに配置し、HTMLのimport文を変更してください。
