# AETHER FRONTIER / No.16
## AEGIS-IX : ルーン装甲守護機・戦闘試作 v1.0

敵ロボットの Three.js 3Dモデル、攻撃予兆、攻撃判定、敵AI、第二形態、体勢崩壊をまとめたモジュールと単体戦闘デモ。

### 収録物

- `AETHER_FRONTIER_No16_Standalone.html` : **このファイル1つで試遊できるHTML**。Three.js本体のみCDNから取得する。
- `index.html` : Cloudflare Pagesへ直接アップロードする際の入口。
- `enemyModule.js` : **統合用の独立モジュール**。カメラ、レンダラー、プレイヤー入力を一切生成しない。
- `demo.js` : 試遊専用の操作、カメラ、UI、プレイヤー管理、ステージ演出。
- `API.md` : 統合用APIの仕様。
- `qa_simulation.mjs` : 任意のロジック試験。ゲームを遊ぶ際には実行不要。

### デモの遊び方

| 操作 | PC | iPhone |
| --- | --- | --- |
| 移動 | W A S D / 矢印キー | 左ジョイスティック |
| 軽攻撃 | J / 左クリック | 軽攻撃 |
| 強攻撃 | K / E | 強攻撃 |
| 回避 | Space / Shift | 回避 |
| ジャンプ | Q | ジャンプ |
| 視点変更 | C / 右上ボタン | 右上ボタン |
| カメラ回転 | 右ドラッグ | 3D画面をスワイプ |
| リトライ | R / 右上ボタン | 終了画面のリトライ |

画面の「画質: HIGH / LOW」で切り替え可能。iPhone等のタッチ端末ではLOWを初期値とする。

### 攻撃の読み方

- **斬撃**：扇形の赤い床予兆。向きが途中で固定されるので左右へ回避できる。
- **衝撃波**：円形の赤い床予兆。範囲外へ逃げるか、タイミングよくジャンプする。
- **直線レーザー**：細長い赤い床予兆。途中で方向固定されるため横方向へ移動できる。
- 攻撃後の回復中と、体勢崩壊中は弱点状態（受けるダメージ1.55倍）。
- HP50%で第二形態。赤いコアへ変化し、一部の攻撃タイミングが短くなる。

### Cloudflare Pages（ビルド不要）

ZIPを展開した中の `index.html`、`demo.js`、`enemyModule.js` を同じ階層に置き、Cloudflare Pagesの直接アップロードに指定する。その他のファイルは任意。`index.html` が起動ページになる。ビルド、Node.js、Git等は不要。

スタンドアロンHTML単体をホストするときは、アップロード先に合わせて `index.html` とリネームしてもよい。ローカルファイルとして開く場合も単体版を利用する。

### 技術仕様

- Three.js **0.160.0** (CDN `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js`)
- ES Modules、WebGL、ビルド不要、外部画像/音声/フォントなし
- Y軸が上、前方-Z、1 unit ≒ 1m
- PCブラウザ / iPhone 16 Safariをターゲット
- `createAetherModule(THREE,options)` → `root`, `update(dt,context)`, `setQuality(mode)`, `dispose()`
- 外部シーン、カメラ、レンダラー、戦闘システムには依存しない
- 画質LOWではディテールの一部・環境効果を省略し、描画解像度上限を低めに設定

### 動作確認と制限

2026-11-09時点で JavaScript構文検査を実施。AIの動作（追跡、予兆→攻撃、第二形態、撃破、リセット、体勢崩壊、破棄）は**モックThree.jsによるロジック試験**でPASS。

本環境のブラウザ実行環境では外部CDN・ローカルHTTPアクセスが制限されており、実際のWebGL描画とiPhone Safari実機のFPS計測は未実施。60fps/50fpsは測定保証ではない。実機での最終確認を推奨。
